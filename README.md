# Ironlog

A distraction-free, mobile-first workout tracker in a single HTML file.

- Log sets with weight, reps and the previous session's numbers, with a rest timer after each set
- Templates (Push / Pull / Legs examples included), history with duration, volume and PRs
- 60 built-in exercises with animated form demos and cues, plus custom exercises
- kg / lb, light and dark themes

## Running

Open `ironlog.html` in a browser. Data is saved in the browser's local storage. When the page is published as a Claude artifact it also syncs to the viewer's account through the artifact `db` capability.
